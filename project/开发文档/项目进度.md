## 开发原则

1. 原图数据与预览数据分离。
2. 分割线始终使用原图像素坐标保存。
3. 缩放和平移只改变视图，不修改原图。
4. 图片、分割线、选中框和遮罩使用一致的坐标变换。
5. 遮罩透明度只影响预览，不影响原图和导出。
6. 导出始终从原始图片读取像素。
7. 用户功能行为以《功能需求.md》为基准。
8. 功能、结构、接口或开发状态发生变化时，同步维护对应开发文档。
9. 需求和约束没有变化时，不因实现方式变化而修改《功能需求.md》。
10. 实现框架、接口和日志系统发生变化时，及时更新对应实现细节文档。
11. 重要的跨模块行为逻辑不只依赖源码注释，应记录在相应开发文档中。
12. 能够使用现代汉语准确表达时，源码注释和 Git commit 消息优先使用现代汉语。
13. 未经维护者明确沟通和确认，不主动创建 Pull Request。
14. 主窗口工具栏等核心 UI 应优先在窗口类自身的 UI 构建方法中集中定义，避免使用脆弱的类外动态补丁维护核心界面结构。
15. 修改完整源文件时，应确认保留现有功能和最近变更，避免因为使用过时文件内容覆盖而回退已有功能。

## 最近变更

### 编辑状态、导出流程与主窗口实现调整

- 恢复 `Ctrl+Shift+Z` 的标准 Redo 行为。
- 增加“重置”工具栏操作，将当前编辑状态恢复到刚打开图片时的状态，并纳入 Undo / Redo 历史。
- 增加“关闭图片”操作，用于放弃当前图片编辑并恢复到未打开图片状态。
- 增加独立的“设置”窗口，集中管理导出相关选项。
- 打开图片和导出位置使用独立的目录配置。
- 增加自定义导出命名前缀、后缀及其持久化。
- 增加导出文件重名冲突处理，在写入文件前允许用户选择替换、跳过或取消。
- 修复取消导出时被通用异常处理误判为“导出失败”的问题。
- 修复取消导出时创建空输出目录的问题。
- 修复主窗口工具栏“重置”和“设置”按钮因类外 monkey patch 被意外删除的问题。
- 将“重置”和“设置”直接纳入 `MainWindow._build_ui()`，并直接维护“重置”按钮的启用状态。
- 将 `edit_settings()` 恢复为 `MainWindow` 的正常方法，并补充显式 `QDialog` 导入。
- 更新《项目结构.md》《公开接口.md》《项目进度.md》，记录新的主窗口 UI 构建方式和本次修复经验。
