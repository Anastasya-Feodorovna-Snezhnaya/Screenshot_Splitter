# 项目结构

本文档属于**实现细节说明**，描述当前代码的目录、模块职责、模块关系和主要数据流。代码结构发生变化时应及时更新；用户功能要求不因这里的实现变化而自动改变。

## 模块职责

### `main.py`

程序入口。负责解析命令行参数、创建 Qt 应用、初始化配置管理器、初始化调试日志并创建主窗口。

### `src/config.py`

负责快捷键、预览遮罩、最近使用目录、导出位置、导出后原图处理方式以及自定义命名等用户设置的数据结构、读取和保存。

### `src/logger.py`

负责可选的运行时调试日志，包括程序生命周期、启动运行上下文、键盘/鼠标/滚轮事件、画布交互、状态快照和未捕获异常。日志写入 `logs/`，使用 JSON Lines 格式。

### `src/model.py`

负责核心编辑状态的数据模型，包括原图信息、分割线和区域状态。

### `src/image_canvas.py`

负责图片预览和鼠标/键盘交互，包括原图绘制、缩放、滚动、画布平移、分割线创建/选择/拖动/删除、区域相关操作以及预览遮罩和选中效果。

当前实现通过 `QAbstractScrollArea` 的 viewport 绘制图片，并使用 viewport 事件过滤机制处理鼠标事件。

### `src/exporter.py`

根据文档状态中的原始像素坐标裁剪保留区域，并输出默认命名的 PNG 文件。实际写入前调用导出冲突处理模块检查重名文件。

### `src/custom_exporter.py`

根据用户提供的前缀和包含 `n` 的后缀生成切片文件名，并输出 PNG 文件。实际写入前同样处理文件重名冲突。

### `src/export_conflicts.py`

负责导出前的文件重名检查和用户决策。针对每个重名文件提供“替换”“跳过”“取消”三个选项，并在全部冲突处理完成前不开始写入导出文件。

### `src/rename_dialog.py`

负责自定义导出文件名前缀和后缀的输入以及 Windows 文件名合法性校验。

### `src/settings_dialog.py`

负责应用“设置”二级窗口，目前集中提供导出相关配置。

### `src/shortcut_dialog.py`

提供快捷键配置页面，负责编辑快捷键字符串、规范化并检查重复绑定。

### `src/main_window.py`

主窗口和应用层协调模块，负责工具栏、状态栏、文件选择、快捷键分发、遮罩设置、编辑状态重置和导出操作，同时记录主要状态变化。

## 模块关系

```text
main.py
  │
  ├── ConfigManager ── settings.json
  │
  ├── DebugLogger ─── logs/*.jsonl
  │       └── QApplication 事件过滤器
  │
  └── MainWindow
        │
        ├── ImageCanvas ── DocumentState / SplitLine / Region
        ├── ShortcutEditDialog ── ConfigManager
        ├── SettingsDialog ── ConfigManager
        ├── RenameDialog ── 自定义命名校验
        ├── exporter ── ExportConflicts ── DocumentState
        └── custom_exporter ── ExportConflicts ── DocumentState
```

## GUI 层级

当前版本不设置独立菜单栏，主界面功能统一通过工具栏提供。

```text
MainWindow
├─ ToolBar
│  ├─ 打开
│  ├─ 关闭图片
│  ├─ 适应窗口
│  ├─ 原始尺寸
│  ├─ 遮罩设置
│  ├─ 重置
│  ├─ 导出全部
│  ├─ 设置
│  └─ 设置快捷键
├─ ImageCanvas
│  └─ viewport
│     ├─ 原图
│     ├─ 分割线
│     ├─ 区域半透明遮罩
│     └─ 分割线选中效果
└─ StatusBar
```

“设置”打开独立二级窗口；当前窗口包含导出位置、导出后原图处理和默认/自定义命名等选项。

## 数据流原则

```text
原始 PNG
   │
   ├── QImage ──> ImageCanvas ──> 预览
   │                    │
   │                    └── 编辑 DocumentState
   │
   └── Pillow ──> exporter/custom_exporter
                       │
                       └── export_conflicts ──> 最终 PNG
```

预览使用 `QImage`，导出使用原始图片文件。缩放、平移和预览遮罩只改变视图或编辑状态，不改变原始图片像素。

导出文件在实际写入前完成重名冲突确认；用户取消时不会开始写入本次导出的切片。

## 调试日志

日志默认关闭。启用后写入与 `settings.json` 同目录的 `logs/`。开发运行时为 `project/logs/`；打包运行时为 EXE 所在目录下的 `logs/`。

详细的日志分类、通用运行上下文、字段和排查方法见《调试日志.md》。

日志目录不提交 Git；本地测试 PNG 也不提交 Git。
