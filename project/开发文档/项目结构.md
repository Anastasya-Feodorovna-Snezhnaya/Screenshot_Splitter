# 项目结构

## 目录结构

```text
project/
├─ main.py
├─ requirements.txt
├─ README.md
├─ settings.json              # 运行后生成，不作为项目源码
├─ logs/                      # 运行时生成，不提交 Git
├─ *.png                      # 本地测试图片，不提交 Git
├─ 开发文档/
│  ├─ 开发文档说明.md
│  ├─ 功能需求.md
│  ├─ 项目结构.md
│  ├─ 公开接口.md
│  └─ 项目进度.md
└─ src/
   ├─ __init__.py
   ├─ config.py
   ├─ logger.py
   ├─ model.py
   ├─ image_canvas.py
   ├─ exporter.py
   ├─ shortcut_dialog.py
   └─ main_window.py
```

## 模块职责

### `main.py`

程序入口。负责解析命令行参数、创建 Qt 应用、初始化配置管理器、初始化调试日志并创建主窗口。

### `src/config.py`

负责快捷键配置以及预览遮罩透明度等用户设置的数据结构、读取和保存。

### `src/logger.py`

负责可选的运行时调试日志，包括键盘/鼠标/滚轮事件、主要程序接口、状态快照和未捕获异常。日志写入 `logs/`，使用 JSON Lines 格式。

### `src/model.py`

负责核心编辑状态的数据模型，包括原图信息、分割线和区域状态。

### `src/image_canvas.py`

负责图片预览和鼠标/键盘交互，包括原图绘制、缩放、滚动、画布平移、分割线创建/选择/拖动/删除、区域选择以及预览遮罩和选中框。

### `src/exporter.py`

根据文档状态中的原始像素坐标裁剪保留区域，并输出 PNG 文件。

### `src/shortcut_dialog.py`

提供快捷键配置页面，负责编辑快捷键字符串并检查重复绑定。

### `src/main_window.py`

主窗口和应用层协调模块，负责工具栏、状态栏、文件选择、快捷键分发、遮罩设置和导出操作，同时记录主要接口和状态变化。

## 模块关系

```text
main.py
  │
  ├── ConfigManager ── settings.json
  │
  ├── DebugLogger ─── logs/*.jsonl
```

## 数据流原则

```text
原始 PNG
   │
   ├── QImage ──> ImageCanvas ──> 预览
   │                    │
   │                    └── 编辑 DocumentState
   │
   └── Pillow ──> exporter ──> 最终 PNG
```

预览使用 `QImage`，导出使用原始图片文件。缩放、平移和预览遮罩只改变视图或编辑状态，不改变原始图片像素。

## 调试日志

日志默认关闭。启用后写入与 `settings.json` 同目录的 `logs/`。开发运行时为 `project/logs/`；打包运行时为 EXE 所在目录下的 `logs/`。

日志文件格式：

```text
logs/debug_YYYYMMDD_HHMMSS_microseconds.jsonl
```

每行是一条 JSON 记录，包含时间、类别、事件名称和具体数据。日志目录不提交 Git；本地测试 PNG 也不提交 Git。

### 命令行参数

```text
--log
--log-events
--log-api
--log-state
```

`--log` 是总开关。启用 `--log` 后，如果没有指定分类参数，则记录全部类别。

| 参数 | 记录内容 |
|---|---|
| `--log-events` | QApplication 收到的键盘、鼠标、滚轮事件，以及目标控件、修饰键、位置、滚轮增量等 |
| `--log-api` | 主要程序接口的调用、结果及关键参数 |
| `--log-state` | 当前图片、分割线、区域状态、选区、缩放、遮罩透明度等状态快照 |

示例：

```text
python main.py --log
python main.py --log --log-events
python main.py --log --log-events --log-api --log-state
```

如果未指定 `--log`，即使指定了分类参数，也不会启用日志。
