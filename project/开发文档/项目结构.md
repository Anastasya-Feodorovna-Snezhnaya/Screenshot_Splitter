# 项目结构

## 目录结构

```text
project/
├─ main.py
├─ requirements.txt
├─ README.md
├─ settings.json              # 运行后生成，不作为项目源码
├─ 开发文档/
│  ├─ 开发文档说明.md
│  ├─ 功能需求.md
│  ├─ 项目结构.md
│  ├─ 公开接口.md
│  └─ 项目进度.md
└─ src/
   ├─ __init__.py
   ├─ config.py
   ├─ model.py
   ├─ image_canvas.py
   ├─ exporter.py
   ├─ shortcut_dialog.py
   └─ main_window.py
```

## 模块职责

### `main.py`

程序入口。负责创建 Qt 应用、初始化配置管理器并创建主窗口。

### `src/config.py`

负责快捷键配置的数据结构以及 `settings.json` 的读取和保存。

### `src/model.py`

负责核心编辑状态的数据模型，包括原图信息、分割线和区域状态。

### `src/image_canvas.py`

负责图片预览和鼠标/键盘交互，包括：

- 原图绘制
- 缩放
- 滚动
- 画布平移
- 分割线创建、选择、拖动和删除
- 区域选择
- 预览层遮罩和选中框

其中图片、分割线、选中框和遮罩统一使用图片坐标与视口坐标之间的变换，保证平移时视觉元素保持一致。

### `src/exporter.py`

根据文档状态中的原始像素坐标裁剪保留区域，并输出 PNG 文件。

### `src/shortcut_dialog.py`

提供快捷键配置页面，负责编辑快捷键字符串并检查重复绑定。

### `src/main_window.py`

主窗口和应用层协调模块，负责工具栏、状态栏、文件选择、快捷键分发和导出操作。

## 模块关系

```text
main.py
  │
  ├── ConfigManager ── settings.json
  │
  └── MainWindow
        │
        ├── ImageCanvas ── DocumentState / SplitLine / Region
        ├── ShortcutEditDialog ── ConfigManager
        └── exporter.export_regions() ── DocumentState
```

```text

├─ ToolBar
│  ├─ 打开
│  ├─ 适应窗口并居中
│  ├─ 100%
│  ├─ 导出全部
│  └─ 设置快捷键
├─ ImageCanvas
│  └─ viewport
│     ├─ 原图
│     ├─ 分割线
│     ├─ 区域灰色遮罩
│     └─ 区域蓝色选中框
└─ StatusBar
```

## 数据流原则

```text
原始 PNG
   │
   ├── QImage ──> ImageCanvas ──> 预览
   │                    │
   │                    └── 编辑 DocumentState
   │
   └── Pillow ──> exporter ──> 最终 PNG
```

预览使用 `QImage`，导出使用原始图片文件。缩放、平移和预览遮罩只改变视图或编辑状态，不改变原始图片像素。
