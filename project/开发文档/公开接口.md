# 公开接口

本文档属于**实现细节说明**，只记录当前模块中供其他模块调用的公开接口。私有方法（名称以下划线开头）不列入接口清单。

如果公开接口的签名、生命周期或重要行为发生变化，应及时更新本文档。这里记录的是当前实现提供的接口，而不是用户功能需求；用户可观察的功能要求仍以《功能需求.md》为准。

## `src/config.py`

### `ShortcutConfig`

快捷键配置数据类。

| 成员 | 类型 | 说明 |
| --- | --- | --- |
| `add_split_line` | `str` | 添加分割线快捷键，默认 `S` |
| `toggle_region` | `str` | 切换区域保留/删除，默认 `SPACE` |
| `delete_split_line` | `str` | 删除分割线快捷键，默认 `DELETE` |
| `undo` | `str` | 撤销快捷键配置，默认 `CTRL+Z` |
| `redo` | `str` | 重做快捷键配置，默认 `CTRL+SHIFT+Z` |
| `move_line_up` | `str` | 分割线向上移动 1px |
| `move_line_down` | `str` | 分割线向下移动 1px |
| `move_line_up_fast` | `str` | 分割线向上移动 10px |
| `move_line_down_fast` | `str` | 分割线向下移动 10px |
| `fit_window` | `str` | 适应窗口，默认 `F` |
| `zoom_100` | `str` | 原始尺寸（1:1）快捷键，默认 `1` |

### `PreviewConfig`

预览显示配置数据类。

| 成员 | 类型 | 说明 |
| --- | --- | --- |
| `mask_opacity` | `int` | 删除区域遮罩透明度，范围 `0~100`，默认 `55` |

### `ConfigManager(base_dir: Path)`

创建配置管理器。

- 参数：`base_dir`，配置文件所在目录。
- 返回值：`ConfigManager` 实例。

### `ConfigManager.load() -> None`

读取 `settings.json`。文件不存在时创建默认配置；配置无效时恢复默认配置。

### `ConfigManager.save() -> None`

将当前快捷键和预览配置保存到 `settings.json`。

## `src/model.py`

### `SplitLine`

表示一条水平分割线。

| 成员 | 类型 | 说明 |
| --- | --- | --- |
| `y` | `int` | 分割线在原图中的 Y 坐标 |

### `Region`

表示由相邻分割线确定的图片区域。

| 成员 | 类型 | 说明 |
| --- | --- | --- |
| `top` | `int` | 区域上边界，原图 Y 坐标 |
| `bottom` | `int` | 区域下边界，原图 Y 坐标 |
| `keep` | `bool` | 是否保留该区域 |

### `Region.height -> int`

返回区域高度。结果不会小于 0。

### `DocumentState`

保存当前编辑文档的核心状态。

主要成员：`image_path`、`image_width`、`image_height`、`split_lines`、`deleted_regions`。

### `DocumentState.normalized_lines() -> list[int]`

返回排序、去重并限制在有效图片高度范围内的分割线 Y 坐标。

### `DocumentState.regions() -> list[Region]`

根据图片高度和分割线生成连续区域，并结合 `deleted_regions` 确定各区域的 `keep` 状态。

## `src/image_canvas.py`

### `ImageCanvas(parent=None)`

图片预览和交互控件。

当前实现使用 `QAbstractScrollArea` 的 viewport 作为实际绘制区域；viewport 的鼠标事件通过事件过滤机制进入画布内部处理。该实现细节用于保证绘制和鼠标交互路由的一致性。

### `ImageCanvas.set_document(image: QImage, state: DocumentState) -> None`

设置当前预览图片和对应编辑状态，并重置视图缩放和选择状态。

### `ImageCanvas.set_mask_opacity(opacity: int) -> None`

设置删除区域预览遮罩透明度，范围为 `0~100%`。

### `ImageCanvas.image_point(pos: QPointF) -> QPointF`

将预览区域坐标转换为原图坐标。转换结果会考虑当前缩放比例和滚动位置。

### `ImageCanvas.set_zoom(zoom: float) -> None`

设置预览缩放比例，并尽量保持当前视图中心对应的原图位置不变。

### `ImageCanvas.fit_to_window() -> None`

计算能够完整显示图片的缩放比例，使图片适应当前预览窗口，并将图片整体居中。

### 信号

| 信号 | 参数 | 说明 |
| --- | --- | --- |
| `splitLineSelected` | `int` | 用户选中了分割线，参数为分割线索引 |
| `splitLineMoved` | `int, int` | 分割线位置发生变化，参数为旧 Y、新 Y |
| `splitLineMoveFinished` | `int, int` | 一次连续分割线拖动结束，参数为拖动开始时的旧 Y、结束时的新 Y |
| `splitLineCreated` | `int` | 创建分割线，参数为 Y 坐标 |
| `splitLineDeleted` | `int` | 删除分割线，参数为被删除的 Y 坐标 |
| `zoomChanged` | `float` | 预览缩放比例发生变化，参数为新的缩放比例 |

当前 `ImageCanvas` 实现没有发出 `regionSelected` 信号；区域切换由主窗口根据鼠标位置直接确定。

## `src/exporter.py`

### `export_regions(state: DocumentState, output_dir: Path) -> list[Path]`

根据当前文档状态，将所有保留区域从原始 PNG 中裁剪并导出。

- 参数：
  - `state`：当前编辑状态。
  - `output_dir`：输出目录，不存在时会创建。
- 返回值：实际生成的 PNG 文件路径列表。
- 异常：未设置原图、原图尺寸与记录不一致等情况下抛出异常。

## `src/shortcut_dialog.py`

### `ShortcutEditDialog(config: ConfigManager, parent=None)`

创建快捷键编辑对话框。

- 参数：`config` 为配置管理器；`parent` 为 Qt 父控件。
- 返回值：对话框实例。
- 调用 `exec()` 后根据用户操作返回 Qt 对话框结果。

当前实现使用 `QKeySequence` 的 PortableText 格式解析并规范化快捷键；保存前检查格式和重复绑定，保存失败时恢复原配置。

## `src/main_window.py`

### `MainWindow(config: ConfigManager, logger: DebugLogger | None = None)`

创建主应用窗口并协调配置、图片预览、编辑状态和导出功能。

- 参数：`config`，应用配置管理器；`logger` 为可选调试日志器。
- 返回值：`MainWindow` 实例。

### `MainWindow.open_image(path: str | None = None) -> None`

打开 PNG 文件并建立新的编辑文档。未提供 `path` 时弹出文件选择框；图片载入后自动适应预览窗口。

### `MainWindow.edit_mask_opacity() -> None`

打开遮罩设置对话框，修改并保存删除区域预览遮罩透明度，同时立即刷新预览。

### `MainWindow.export_all() -> None`

选择输出目录并导出所有保留区域。

### `MainWindow.edit_shortcuts() -> None`

打开快捷键设置对话框。保存成功后重新注册主窗口快捷键，无需重启程序。

### 快捷键与 GUI 名称同步规则

快捷键设置页面中的功能描述必须与主界面对应功能的当前 GUI 名称保持一致。

当工具栏或菜单中的某个功能按钮/菜单项文字发生变更时，如果该功能存在于快捷键设置页面，必须同步更新快捷键设置页面中的对应描述。例如主界面的“100% 缩放”改为“原始尺寸”后，快捷键设置中的对应描述也必须改为“原始尺寸”。

该规则只约束用户可见的功能名称；内部配置字段名可以继续保持兼容，例如 `zoom_100` 可以继续作为配置字段名，但其 GUI 描述应显示为“原始尺寸”。

### 快捷键生效规则

快捷键设置页面修改并保存后，主窗口必须立即重新注册相关快捷键，无需重启程序。只有已经实现的功能才应绑定实际操作；尚未实现的配置项可以保存，但不能宣称已经生效。
