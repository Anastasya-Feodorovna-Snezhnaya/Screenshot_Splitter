# 功能需求

本文档从用户可观察的功能和操作流程描述 Screenshot Splitter 的需求，不规定具体代码实现。

## 1. 软件目标

用于处理超长 PNG 截图：打开长截图后，通过水平分割线划分区域，标记需要删除的区域，最后将保留区域从原图裁剪并导出。

预览中的缩放、平移、分割线显示和删除遮罩均不得修改原始图片像素。

## 2. 主窗口

```text
┌──────────────────────────────────────────────────────────────┐
│ [打开] [适应窗口] [原始尺寸] [遮罩设置] [导出全部] [设置快捷键] │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                         图片预览                              │
│                                                              │
├──────────────────────────────────────────────────────────────┤
│ 就绪  区域：N  保留：N  删除：N  分割线：N  缩放：xx.x%       │
└──────────────────────────────────────────────────────────────┘
```

## 3. 图片打开

- “打开”选择 PNG 图片。
- 打开成功后显示图片，记录原始宽高，并自动适应窗口、居中显示。
- 新打开的图片不继承上一张图片的分割线和区域删除状态。
- 图片已经打开时，拖入新的 PNG 不应自动覆盖当前图片。
- 未打开图片时，可以将 PNG 文件拖入窗口直接打开。
- 无法读取的图片通过界面提示，不应导致程序崩溃。

## 4. 图片预览

### 4.1 适应窗口

整张图片尽可能完整显示，保持原始宽高比并居中。执行后恢复默认预览位置。快捷键默认为 `F`。

### 4.2 原始尺寸

以 1:1 像素比例显示原图，即原图 1 像素对应预览 1 像素。快捷键默认为 `Y`。

### 4.3 Alt + 滚轮缩放

- 按住 `Alt` 滚轮向前放大、向后缩小。
- 缩放以鼠标当前位置对应的图片位置为锚点。
- 普通滚轮不滚动图片。
- 缩放只影响预览，不影响原图和导出结果。

### 4.4 画布平移

- 左键按住并拖动：平移图片。
- 中键按住并拖动：平移图片。
- 图片、分割线和删除遮罩必须同步移动。
- 左键拖动用于平移；左键点击分割线用于选中分割线。

## 5. 区域

### 5.1 区域定义

图片顶部和底部以及所有分割线共同构成区域边界。分割线按 Y 坐标排序后形成连续区域。

例如图片高度为 `20000`，分割线为 `7350`、`12000`：

```text
┌──────────────┐
│    区域 1    │ 0 ~ 7350
├──────────────┤ 7350
│    区域 2    │ 7350 ~ 12000
├──────────────┤ 12000
│    区域 3    │ 12000 ~ 20000
└──────────────┘
```

### 5.2 保留/删除

区域默认均为“保留”。删除区域显示半透明遮罩；再次切换后恢复为“保留”并立即取消遮罩。

区域状态必须由其当前上下边界确定，而不是由区域当前序号确定。这样新增或删除其他位置的分割线时，不应因为区域序号变化而错误迁移删除状态。

Space 的行为如下：

1. 快捷键真正触发时，读取此刻的鼠标位置。
2. 如果鼠标不在图片内容范围内，则不执行任何操作。
3. 如果此刻有鼠标按键处于按下状态，则不执行任何操作。
4. 如果鼠标位于图片内，则直接确定鼠标所在区域并切换该区域的保留/删除状态。
5. 不需要追踪鼠标移动，也不需要根据鼠标是否移动过来决定操作对象。

当前版本不显示区域选中蓝色边框，也不提供“先点击区域、再由 Space 操作选中区域”的交互。

## 6. 分割线

### 6.1 添加

默认快捷键为 `S`。添加位置取当前鼠标在图片中的 Y 坐标。分割线必须位于图片上下边界之间，且不能与已有分割线重合。

### 6.2 选择

鼠标点击分割线附近即可选中。选中的分割线具有明显的视觉区别。

### 6.3 拖动

可以拖动选中的分割线改变 Y 坐标。不能越过相邻分割线，也不能超出图片边界。

一次连续拖动属于一次编辑操作，撤销时应整体撤销该次拖动，而不是逐个鼠标移动位置撤销。

### 6.4 键盘移动

选中分割线后：

- `↑`：向上 1 px。
- `↓`：向下 1 px。
- `Shift+↑`：向上 10 px。
- `Shift+↓`：向下 10 px。
- `Delete`：删除分割线。

默认快捷键分别为 `UP`、`DOWN`、`SHIFT+UP`、`SHIFT+DOWN`、`DELETE`。

### 6.5 区域状态与分割线变化

区域删除状态使用区域上下边界作为稳定标识，并遵循以下规则：

- 在一个已删除区域**外部**新增分割线，不应改变该已删除区域的状态；新增分割线产生的新区域默认为保留。
- 在一个已删除区域**内部**新增分割线后，原来的区域边界已经不再对应当前区域，因此原删除状态失效；由新分割线形成的区域默认为保留。
- 删除作为某个区域边界的分割线后，与该边界相关的旧删除状态失效。
- 移动分割线时，如果该分割线是已删除区域的上下边界，则删除状态应随边界移动到新的区域边界。
- 分割线变化后，任何已经不再对应当前实际区域的删除状态都必须失效。

## 7. 撤销与重做

提供 `Undo` / `Redo`。

- 默认撤销：`Ctrl+Z`。
- 默认重做：`Ctrl+Shift+Z`。
- 撤销和重做只针对可编辑文档状态，包括分割线和区域保留/删除状态。
- 打开新图片后建立新的历史起点，不继承上一张图片的编辑历史。
- 撤销后进行新的编辑，应清除该位置之后的重做历史。
- 分割线连续拖动作为一次历史操作。
- 历史恢复后，预览应立即反映恢复后的分割线和区域状态。

## 8. 遮罩

“遮罩设置”用于调整删除区域的预览遮罩透明度。

- 默认 `55%`。
- 输入 `55` 或 `55%` 均表示 55%。
- 只接受 `0` 到 `100` 的整数。
- `0%` 完全透明，`100%` 完全不透明。
- 修改后立即应用并保存到 `settings.json`。
- 遮罩只属于预览，不影响导出。

## 9. 导出

“导出全部”将所有当前为“保留”的区域从原始 PNG 裁剪并导出。

- 导出宽度与原图宽度一致。
- 删除区域不导出。
- 缩放、平移、遮罩透明度不影响导出像素。

## 10. 快捷键设置

快捷键设置窗口显示全部可配置快捷键。

默认配置：

| 功能 | 快捷键 |
|---|---|
| 添加水平分割线 | `S` |
| 切换区域保留/删除 | `SPACE` |
| 删除选中分割线 | `DELETE` |
| 撤销 | `CTRL+Z` |
| 重做 | `CTRL+SHIFT+Z` |
| 分割线向上 1px | `UP` |
| 分割线向下 1px | `DOWN` |
| 分割线向上 10px | `SHIFT+UP` |
| 分割线向下 10px | `SHIFT+DOWN` |
| 适应窗口 | `F` |
| 原始尺寸 | `Y` |

所有应用快捷键只在本程序主窗口处于活动状态时生效。

保存快捷键时：

- 空白表示禁用该快捷键。
- 无效快捷键不能保存。
- 同一个快捷键不能绑定给多个应用功能。
- 检查失败时保持原来的有效配置不变，快捷键设置窗口继续打开，用户可以修改后重新保存。
- 只有用户取消或关闭设置窗口时，才放弃当前未成功应用的修改并返回主窗口。

快捷键配置保存到 `settings.json`，成功修改后立即生效，无需重启程序。

## 11. 窗口状态

程序关闭时保存主窗口状态；下次启动时恢复：

- 普通窗口的位置。
- 普通窗口的宽度和高度。
- 是否处于全屏状态。

如果保存的位置已经不再位于可用显示区域，或者保存尺寸明显异常，则使用合理的默认尺寸并将窗口放置在可用屏幕区域内。

## 12. 配置持久化

`settings.json` 保存用户配置，包括：

- 快捷键。
- 删除区域遮罩透明度。
- 主窗口状态。

配置文件缺失或无效时使用默认配置，不应阻止程序启动。
