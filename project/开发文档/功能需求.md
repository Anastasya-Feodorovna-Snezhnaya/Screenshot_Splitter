# 功能需求

本文档从用户可观察的功能和操作流程描述 Screenshot Splitter 的需求，不规定具体代码实现。

## 1. 软件目标

用于处理超长 PNG 截图：打开长截图后，通过水平分割线划分区域，标记需要删除的区域，最后将保留区域从原图裁剪并导出。

预览中的缩放、平移、分割线显示和删除遮罩均不得修改原始图片像素。

## 2. 主窗口

```text
┌────────────────────────────────────────────────────────────────────────────┐
│ [打开] [关闭图片] [适应窗口] [原始尺寸] [遮罩设置] [重置] [导出全部] [设置] [设置快捷键] │
├────────────────────────────────────────────────────────────────────────────┤
│                                                                            │
│                              图片预览                                      │
│                                                                            │
├────────────────────────────────────────────────────────────────────────────┤
│ 就绪  区域：N  保留：N  删除：N  分割线：N  缩放：xx.x%                    │
└────────────────────────────────────────────────────────────────────────────┘
```

### 2.1 关闭图片

- “关闭图片”只关闭当前打开的图片，不删除磁盘上的原文件。
- 关闭后放弃当前图片的全部编辑状态，恢复到未打开图片的界面。
- 关闭后当前图片的 Undo / Redo 历史全部清除。
- 没有打开图片时，“关闭图片”和“重置”不可用。

### 2.2 重置

“重置”用于清除当前图片的全部编辑状态，使其恢复到**刚打开该图片时的编辑状态**。

- 清除全部分割线。
- 清除全部区域删除状态。
- 不修改原始图片文件。
- 不改变当前图片、缩放或平移状态。
- 不分配快捷键。
- 重置本身属于一次可撤销的编辑操作：执行重置后可以使用 Undo 恢复重置前的编辑状态。

## 3. 图片打开

- “打开”选择 PNG 图片。
- 打开成功后显示图片，记录原始宽高，并自动适应窗口、居中显示。
- 新打开的图片不继承上一张图片的分割线和区域删除状态。
- 图片已经打开时，拖入新的 PNG 不应自动覆盖当前图片。
- 未打开图片时，可以将 PNG 文件拖入窗口直接打开。
- 无法读取的图片通过界面提示，不应导致程序崩溃。
- “打开”文件选择器默认定位到用户上一次成功选择 PNG 图片所在的目录。
- 上一次打开目录持久化到 `settings.json`，与导出位置相互独立。
- 如果记忆的目录已经不存在，则使用文件选择器的默认目录。

## 4. 图片预览

### 4.1 适应窗口

整张图片尽可能完整显示，保持原始宽高比并居中。执行后恢复默认预览位置。快捷键默认为 `F`。

### 4.2 原始尺寸

以 1:1 像素比例显示原图，即原图 1 像素对应预览 1 像素。快捷键默认为 `Y`。

### 4.3 Alt + 滚轮缩放

- 按住 `Alt` 滚轮向前放大、向后缩小。
- 缩放以鼠标当前位置对应的图片位置为锚点。
- 普通滚轮不滚动图片。
- 缩放只影响预览，不影响原图和导出结果。

### 4.4 画布平移

- 左键按住并拖动：平移图片。
- 中键按住并拖动：平移图片。
- 图片、分割线和删除遮罩必须同步移动。
- 左键拖动用于平移；左键点击分割线用于选中分割线。

## 5. 区域

### 5.1 区域定义

图片顶部和底部以及所有分割线共同构成区域边界。分割线按 Y 坐标排序后形成连续区域。

### 5.2 保留/删除

区域默认均为“保留”。删除区域显示半透明遮罩；再次切换后恢复为“保留”并立即取消遮罩。

区域状态必须由其当前上下边界确定，而不是由区域当前序号确定。这样新增或删除其他位置的分割线时，不应因为区域序号变化而错误迁移删除状态。

Space 的行为如下：

1. 快捷键真正触发时，读取此刻的鼠标位置。
2. 如果鼠标不在图片内容范围内，则不执行任何操作。
3. 如果此刻有鼠标按键处于按下状态，则不执行任何操作。
4. 如果鼠标位于图片内，则直接确定鼠标所在区域并切换该区域的保留/删除状态。
5. 不需要追踪鼠标移动，也不需要根据鼠标是否移动过来决定操作对象。

当前版本不显示区域选中蓝色边框，也不提供“先点击区域、再由 Space 操作选中区域”的交互。

## 6. 分割线

### 6.1 添加

默认快捷键为 `S`。添加位置取当前鼠标在图片中的 Y 坐标。分割线必须位于图片上下边界之间，且不能与已有分割线重合。

### 6.2 选择

鼠标点击分割线附近即可选中。选中的分割线具有明显的视觉区别。

### 6.3 拖动

可以拖动选中的分割线改变 Y 坐标。不能越过相邻分割线，也不能超出图片边界。

一次连续拖动属于一次编辑操作，撤销时应整体撤销该次拖动，而不是逐个鼠标移动位置撤销。

### 6.4 键盘移动

选中分割线后：

- `↑`：向上 1 px。
- `↓`：向下 1 px。
- `Shift+↑`：向上 10 px。
- `Shift+↓`：向下 10 px。
- `Delete`：删除分割线。

默认快捷键分别为 `UP`、`DOWN`、`SHIFT+UP`、`SHIFT+DOWN`、`DELETE`。

### 6.5 区域状态与分割线变化

区域删除状态使用区域上下边界作为稳定标识，并遵循以下规则：

- 在一个已删除区域**外部**新增分割线，不应改变该已删除区域的状态；新增分割线产生的新区域默认为保留。
- 在一个已删除区域**内部**新增分割线后，原来的区域边界已经不再对应当前区域，因此原删除状态失效；由新分割线形成的区域默认为保留。
- 删除作为某个区域边界的分割线后，与该边界相关的旧删除状态失效。
- 移动分割线时，如果该分割线是已删除区域的上下边界，则删除状态应随边界移动到新的区域边界。
- 分割线变化后，任何已经不再对应当前实际区域的删除状态都必须失效。

## 7. 撤销与重做

提供标准 `Undo` / `Redo`。

- 默认撤销：`Ctrl+Z`。
- 默认重做：`Ctrl+Shift+Z`。
- 撤销和重做只针对可编辑文档状态，包括分割线和区域保留/删除状态。
- “重置”也是一次可撤销的编辑操作，因此执行重置后可以通过 Undo 恢复重置前的状态，并可以通过 Redo 再次恢复到重置后的状态。
- 打开新图片后建立新的历史起点，不继承上一张图片的编辑历史。
- 撤销后进行新的编辑，应清除该位置之后的重做历史。
- 分割线连续拖动作为一次历史操作。
- 历史恢复后，预览应立即反映恢复后的分割线和区域状态。

## 8. 遮罩

“遮罩设置”用于调整删除区域的预览遮罩透明度。

- 默认 `55%`。
- 输入 `55` 或 `55%` 均表示 55%。
- 只接受 `0` 到 `100` 的整数。
- `0%` 完全透明，`100%` 完全不透明。
- 修改后立即应用并保存到 `settings.json`。
- 遮罩只属于预览，不影响导出。

## 9. 设置

“设置”打开独立的二级设置窗口，用于集中管理应用的细化选项。

当前只有“导出”相关设置，未来可以继续增加其他功能分类。

### 9.1 导出位置

- 可选择一个目录作为导出位置。
- 默认导出位置为空配置，即使用当前原图所在目录。
- 用户选择其他目录后，该目录持久化到 `settings.json`。
- 导出位置配置与“打开”最近使用目录相互独立。
- 设置的导出目录不存在时，应用可以创建该目录；无法使用时回退到当前原图所在目录。

### 9.2 导出后处理原图

- 默认不删除原图。
- 用户可以开启“导出成功后将原图移至回收站”。
- 只有切片全部完成导出后才执行原图移入回收站。
- 使用 Windows 回收站机制，而不是永久删除。
- 原图处理失败时，应提示用户；已经成功导出的切片不应被撤销。

### 9.3 切片导出命名

提供“切片导出使用默认命名”选项，默认开启。

默认命名保持当前逻辑：按切片在原图中的上下位置顺序编号，例如：

```text
001.png
002.png
003.png
```

如果关闭默认命名，则每次执行导出时要求用户输入：

- 文件名前缀。
- 文件名后缀。

后缀必须包含小写字母 `n`，`n` 表示当前导出的切片序号。

例如：

```text
前缀：变长实参
后缀：(n)
```

则导出结果为：

```text
变长实参(1).png
变长实参(2).png
变长实参(3).png
```

前缀和后缀均作为文件名的一部分，因此必须符合 Windows 文件名规则。

输入时应检查：

- 不得包含 `< > : " / \\ | ? *`。
- 不得包含 Windows 文件名控制字符。
- 生成的文件名不得以空格或句点结尾。
- 不得使用 Windows 保留设备名，例如 `CON`、`PRN`、`AUX`、`NUL`、`COM1`、`LPT1` 等。
- 后缀必须包含小写 `n`。

发现非法输入时：

1. 提示输入无效。
2. 告知相关 Windows 文件名限制。
3. 保持当前输入内容和提交前的编辑状态。
4. 用户修改后可以再次提交。

只有一次导出实际成功完成后，本次使用的前缀和后缀才保存到 `settings.json`。下次关闭默认命名并再次导出时，优先使用上一次成功导出的自定义前缀和后缀作为初始值。

## 10. 导出

“导出全部”将所有当前为“保留”的区域从原始 PNG 裁剪并导出。

- 导出宽度与原图宽度一致。
- 删除区域不导出。
- 缩放、平移、遮罩透明度不影响导出像素。
- 导出位置使用“设置”中配置的目录；如果未配置，则使用当前原图所在目录。
- 默认命名时使用当前的三位数字顺序命名。
- 非默认命名时使用本次导出窗口确认的前缀和后缀。
- 导出成功后，如果开启了删除原图选项，则将原图移至回收站。

## 11. 快捷键设置

快捷键设置窗口显示全部可配置快捷键。

默认配置：

| 功能 | 快捷键 |
|---|---|
| 添加水平分割线 | `S` |
| 切换区域保留/删除 | `SPACE` |
| 删除选中分割线 | `DELETE` |
| 撤销 | `CTRL+Z` |
| 重做 | `CTRL+SHIFT+Z` |
| 分割线向上 1px | `UP` |
| 分割线向下 1px | `DOWN` |
| 分割线向上 10px | `SHIFT+UP` |
| 分割线向下 10px | `SHIFT+DOWN` |
| 适应窗口 | `F` |
| 原始尺寸 | `Y` |

“重置”不分配快捷键，也不出现在快捷键设置列表中。

所有应用快捷键只在本程序主窗口处于活动状态时生效。

保存快捷键时：

- 空白表示禁用该快捷键。
- 无效快捷键不能保存。
- 同一个快捷键不能绑定给多个应用功能。
- 检查失败时保持原来的有效配置不变，快捷键设置窗口继续打开，用户可以修改后重新保存。
- 只有用户取消或关闭设置窗口时，才放弃当前未成功应用的修改并返回主窗口。

快捷键配置保存到 `settings.json`，成功修改后立即生效，无需重启程序。

## 12. 窗口状态

程序关闭时保存主窗口状态；下次启动时恢复：

- 普通窗口的位置。
- 普通窗口的宽度和高度。
- 是否处于全屏状态。

如果保存的位置已经不再位于可用显示区域，或者保存尺寸明显异常，则使用合理的默认尺寸并将窗口放置在可用屏幕区域内。

## 13. 配置持久化

`settings.json` 保存用户配置，包括：

- 快捷键。
- 删除区域遮罩透明度。
- 主窗口状态。
- 上一次打开图片所在目录。
- 导出设置。
- 上一次成功使用的自定义导出文件名前缀和后缀。

其中“打开图片最近目录”和“导出位置”是两个相互独立的配置。

配置文件缺失或无效时使用默认配置，不应阻止程序启动。
