# 功能需求

本文档从用户功能和操作流程出发，记录 Screenshot Splitter 的核心需求。开发时应以本文档为功能基准，避免实现过程中只关注代码细节而偏离软件用途。

## 1. 软件目标

Screenshot Splitter 用于处理超长的 PNG 截图。用户打开一张长截图后，在预览窗口中通过分割线划分图片区域，再决定哪些区域需要保留，最后将保留区域直接从原图裁剪并导出。

核心原则：预览负责显示和交互，原图负责最终导出。任何缩放、平移、选择、半透明遮罩等预览操作，都不应修改原始图片像素。

## 2. 功能结构

```text
图片处理
├─ 打开图片
├─ 图片预览
│  ├─ 适应窗口并居中
│  ├─ 原始尺寸（1:1）
│  ├─ Alt + 鼠标滚轮缩放
│  ├─ 左键拖动画布
│  ├─ 中键拖动画布
│  └─ 普通滚轮滚动
├─ 区域选择
│  ├─ 鼠标点击区域
│  ├─ 当前区域蓝色边框
│  └─ Space 切换保留/删除
├─ 分割线
│  ├─ 添加分割线
│  ├─ 选择分割线
│  ├─ 拖动分割线
│  ├─ 方向键移动
│  └─ 删除分割线
├─ 遮罩设置
│  └─ 调整删除区域半透明遮罩透明度
└─ 导出
   └─ 导出所有保留区域

辅助功能
├─ 快捷键设置
├─ 配置持久化
└─ Windows 打包
```

## 3. GUI 布局

功能需求中涉及 GUI 绘制和布局的部分，使用 ASCII 图进行辅助描述，便于代码审查时确认元素之间的位置关系。

### 3.1 主窗口

```text
┌──────────────────────────────────────────────────────────────┐
│ [打开] [适应窗口] [原始尺寸] [遮罩设置] [导出全部] [设置快捷键] │ ← 工具栏
├──────────────────────────────────────────────────────────────┤
│                                                              │
│                    ┌──────────────┐                          │
│                    │              │                          │
│                    │     图片     │                          │
│                    │              │                          │
│                    └──────────────┘                          │
│                                                              │
│                  （图片整体居中）                            │ ← 预览区域
├──────────────────────────────────────────────────────────────┤
│ 就绪  区域：1  保留：1  删除：0  分割线：0  缩放：xx.x%      │ ← 状态栏
└──────────────────────────────────────────────────────────────┘
```

主窗口不设置独立菜单栏。当前功能直接通过工具栏提供，避免菜单栏与工具栏重复。

### 3.2 图片坐标与视口坐标

预览区域中的所有图片相关元素都必须使用统一的坐标变换：

```text
原图坐标
   │
   ├── × 缩放比例
   │
   └── − 当前平移量
          ↓
      视口坐标
          ↓
 ┌──────────────────────┐
 │      图片内容        │
 │  ────────────────    │ ← 分割线
 │  ┏━━━━━━━━━━━━━━┓    │ ← 选中框
 │  ░░半透明遮罩░░░░    │ ← 删除区域
 │  ┗━━━━━━━━━━━━━━┛    │
 └──────────────────────┘
```

图片、分割线、选中框和遮罩必须使用同一套图片坐标到视口坐标的变换，因此图片发生水平或垂直平移时，这些元素必须整体跟随图片移动。

### 3.3 区域状态视觉效果

保留区域：

```text
┌──────────────────────────────┐
│                              │
│          原图内容            │
│                              │
└──────────────────────────────┘
```

当前选中区域：

```text
┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓
┃          原图内容            ┃ ← 蓝色选中边框
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛
```

删除区域：

```text
┌──────────────────────────────┐
│░░░░░░░░░░░░░░░░░░░░░░░░░░░░│
│░      原图 + 半透明遮罩      ░│
│░░░░░░░░░░░░░░░░░░░░░░░░░░░░│
└──────────────────────────────┘
```

遮罩必须是半透明的，以便仍能观察删除区域中的图片大致内容。透明度由“遮罩设置”调整。

如果删除区域同时处于选中状态，应同时表现为“半透明遮罩 + 蓝色选中边框”。

## 4. 图片打开

### 4.1 打开

用户通过“打开”功能选择 PNG 长截图。打开成功后，图片显示在预览区域，原始宽高记录到文档状态，初始视图自动执行“适应窗口并居中”，分割线和区域状态重置。打开失败时通过界面提示用户，不应导致程序崩溃。

### 4.2 图片数据约束

- 当前版本只要求支持 PNG。
- 编辑过程中不得修改原始图片。
- 导出必须直接读取原始图片。
- 导出的宽度必须与原图宽度一致。

## 5. 图片预览

### 5.1 适应窗口并居中

让整张图片尽可能完整地显示在当前预览窗口中，同时保持原始宽高比，并使图片整体位于预览区域中央。

该功能同时负责恢复默认的位置状态。因此无论此前进行了多少缩放、水平平移或垂直平移，执行“适应窗口”后都应回到：

```text
          预览区域
┌──────────────────────────────┐
│                              │
│        ┌────────────┐        │
│        │            │        │
│        │    图片    │        │
│        │            │        │
│        └────────────┘        │
│                              │
└──────────────────────────────┘
          ↑ 整体居中
```

不修改原图、分割线原始坐标或导出结果。快捷键默认为 `F`，工具栏提供对应操作。

### 5.2 原始尺寸

“原始尺寸”表示以原图的 1:1 像素比例显示，即原图中的 1 个像素对应预览中的 1 个像素。

该操作不会修改原图，也不会重新计算分割线坐标。图片尺寸超过预览区域时，可以通过平移查看不同位置。快捷键默认为 `1`，工具栏提供对应操作。

### 5.3 Alt + 鼠标滚轮缩放

按住 `Alt` 并滚动鼠标滚轮：滚轮向前放大，向后缩小。每次滚轮变化按照滚轮增量计算缩放倍率，而不是只进行固定的一次跳变。

缩放中心位于鼠标当前位置。缩放前先记录鼠标位置对应的原图坐标，缩放后重新计算平移量，使该原图位置尽量保持在鼠标下方。

```text
缩放前                         缩放后
┌──────────────┐               ┌────────────────────┐
│              │               │                    │
│      ×       │ Alt+滚轮      │        ×           │
│     鼠标      │ ─────────→   │       鼠标          │
│              │               │                    │
└──────────────┘               └────────────────────┘
       ↑                              ↑
   同一个原图位置                 仍保持在鼠标附近
```

缩放只影响预览，不影响导出。缩放范围应受到合理上下限限制。

### 5.4 画布平移

用户需要能够在图片放大后移动查看区域。

- 左键按住并拖动图片：平移画布。
- 中键按住并拖动图片：平移画布。
- 水平拖动时，图片应在窗口中左右移动。
- 垂直拖动时，图片应在窗口中上下移动。
- 图片、分割线、选中框和遮罩必须同步移动。
- 拖动方向应符合直接操作直觉：图片跟随鼠标移动。
- 松开鼠标后结束平移。
- 左键单击图片仍必须能够完成区域选择，因此实现需要区分单击和拖动。

### 5.5 普通滚轮

未按住 `Alt` 时，垂直滚轮用于垂直滚动，`Shift + 滚轮`用于水平滚动。

## 6. 区域选择

### 6.1 区域定义

图片默认是一个区域。添加分割线后，分割线按 Y 坐标从上到下排序，将图片划分为多个连续区域。

例如原图高度为 `20000`，分割线为 `7350` 和 `12000`：

```text
┌──────────────────────┐
│      区域 1          │  0 ~ 7350
├──────────────────────┤  Y = 7350
│      区域 2          │  7350 ~ 12000
├──────────────────────┤  Y = 12000
│      区域 3          │  12000 ~ 20000
└──────────────────────┘
```

### 6.2 鼠标选择区域

用户点击某个区域后，该区域成为当前选中区域，并通过蓝色边框等方式提供明确的视觉反馈。

选中框的左右边界必须与当前图片的左右边界一致，不能固定绘制在窗口的左侧。图片发生平移时，选中框必须随图片整体移动。

### 6.3 Space 切换区域状态

这是核心功能之一。

```text
鼠标点击区域
      ↓
区域成为当前选中区域
      ↓
按 Space
      ↓
区域状态切换
      ↓
┌──────────────┬──────────────┐
│ 保留 → 删除  │ 删除 → 保留  │
└──────────────┴──────────────┘
```

当区域为“删除”状态时，预览中必须在该区域上增加**半透明遮罩**，让用户直观看出该区域不会被导出，同时仍能看到区域内图片的大致内容。遮罩只是预览层效果，不修改原始图片。

当再次按 `Space` 将区域恢复为“保留”时，半透明遮罩必须立即消失，恢复显示原图内容；如果该区域仍处于选中状态，则保留蓝色选中边框。

## 7. 遮罩设置

工具栏提供“遮罩设置”，用于调整删除区域预览遮罩的透明度。

```text
[遮罩设置]
     ↓
┌──────────────────────────────┐
│ 遮罩透明度：55%              │
│                              │
│ 0% ──────────────── 100%     │
│ 透明                 不透明   │
└──────────────────────────────┘
```

要求：

- `0%`：遮罩完全透明，只显示原图。
- `100%`：遮罩完全不透明。
- 中间值：半透明遮罩，仍能观察原图大致内容。
- 默认透明度为 `55%`。
- 透明度只影响预览，不影响导出。
- 设置修改后应立即更新当前预览，并保存到 `settings.json`。

## 8. 分割线

### 8.1 添加

默认快捷键为 `S`。添加位置以当前鼠标对应的原图 Y 坐标为准。分割线不能位于图片边界，应满足 `1 <= Y <= image_height - 1`。

### 8.2 选择

鼠标点击分割线附近区域即可选中分割线。选中的分割线需要有明显的视觉区别，例如增加线宽。

### 8.3 拖动

选中分割线后，可以直接使用鼠标拖动调整其 Y 坐标。分割线不能越过相邻分割线，也不能超出图片上下边界。

### 8.4 键盘移动

选中分割线后：

- `↑`：向上移动 1px。
- `↓`：向下移动 1px。
- `Shift + ↑`：向上移动 10px。
- `Shift + ↓`：向下移动 10px。
- `Delete`：删除分割线。

## 9. 导出

用户选择导出目录后，只导出状态为“保留”的区域。导出顺序必须按照图片从上到下排列，并重新编号为 `001.png`、`002.png`、`003.png`……

导出使用原始图片坐标直接裁剪，不得使用缩放后的预览图。因此预览缩放、平移、遮罩均不影响导出内容和质量，输出宽度等于原图宽度。

## 10. 快捷键设置

软件提供快捷键设置页面，用户可以修改功能对应的快捷键。

| 功能 | 默认快捷键 |
|---|---|
| 添加分割线 | `S` |
| 切换区域保留/删除 | `Space` |
| 删除分割线 | `Delete` |
| 撤销 | `Ctrl+Z` |
| 重做 | `Ctrl+Shift+Z` |
| 分割线向上 | `↑` |
| 分割线向下 | `↓` |
| 分割线快速向上 | `Shift+↑` |
| 分割线快速向下 | `Shift+↓` |
| 适应窗口并居中 | `F` |
| 原始尺寸 | `1` |

尚未实现的快捷键功能不能被文档误认为已经完成，应以《项目进度.md》为准。

## 11. 配置持久化

快捷键和预览遮罩透明度等用户设置保存到 `settings.json`。配置损坏或读取失败时使用默认配置，并保证程序仍然能够启动。

## 12. 文档与实现

开发时应优先保证本文件描述的用户行为成立，再考虑内部实现细节。如果后续修改导致功能需求变化，应先修改本文件，再修改代码和项目进度记录。
