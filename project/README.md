# Screenshot Splitter

Windows 10/11 长截图水平分割工具。项目采用 Python + PySide6，目标是提供直接的“分割线 + 区域筛选 + 批量导出”工作流。

## 功能

- 打开 PNG 长截图并在预览窗口中编辑。
- 添加、拖动、删除水平分割线。
- 点击区域进行选择，并切换区域的保留/删除状态。
- 使用方向键微调选中的分割线。
- 使用 `Alt + 滚轮`缩放预览，并以鼠标位置为缩放中心。
- 使用鼠标左键或中键拖动预览画布；普通滚轮和 `Shift + 滚轮`用于滚动。
- 使用 `F` 让图片自动适应当前预览窗口。
- 使用 `1` 以原始尺寸（1:1）显示图片。
- 删除区域使用可调透明度的半透明预览遮罩。
- 将保留区域按原始像素裁剪并导出为连续编号的 PNG 文件。
- 预览缩放、平移和遮罩不会修改原始图片，也不会影响导出尺寸或画质。

详细的模块接口、项目结构和开发进度见 `开发文档/`。

## 使用方法

### 安装依赖

建议使用 Python 3.11+。

```bash
pip install -r requirements.txt
```

### 运行

```bash
python main.py
```

### 基本操作

1. 点击“打开”，选择 PNG 长截图。
2. 图片打开后会自动适应预览窗口并居中。
3. 默认按 `S` 在鼠标所在位置添加水平分割线。
4. 点击分割线并拖动，可调整分割线位置。
5. 点击图片区域可选择区域；按 `Space` 切换当前区域的保留/删除状态。
6. 按 `F` 可随时重新适应窗口，按 `1` 以原始尺寸显示。
7. 使用 `Alt + 鼠标滚轮`进行放大或缩小；滚轮向前放大，向后缩小。
8. 使用鼠标左键或中键拖动画布查看图片的其他位置。
9. 删除区域会显示半透明遮罩，可通过“遮罩设置”调整透明度。
10. 点击“导出全部”，选择输出目录，导出所有保留区域。

### 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `S` | 在鼠标位置添加分割线 |
| `Space` | 切换当前区域保留/删除 |
| `Delete` | 删除选中的分割线 |
| `↑ / ↓` | 分割线移动 1px |
| `Shift + ↑ / ↓` | 分割线移动 10px |
| `Alt + 滚轮` | 以鼠标位置为中心缩放 |
| `F` | 适应窗口并居中 |
| `1` | 原始尺寸（1:1） |
| 左键 / 中键拖动 | 平移画布 |
| 普通滚轮 | 垂直滚动 |
| `Shift + 滚轮` | 水平滚动 |

“设置快捷键”页面可以修改配置中的快捷键字符串。当前部分复杂组合键尚未完全接入运行时快捷键解析。

## 配置

程序会在运行目录保存 `settings.json`，用于保存快捷键和预览遮罩透明度配置。配置文件无法读取时会恢复为默认配置，不阻止程序启动。

## 依赖

项目运行依赖位于 `requirements.txt`：

- Python 3.11+
- PySide6 6.7 以上、7 以下
- Pillow 10.0 以上、13 以下

## Windows 打包

使用 PyInstaller 打包：

```bash
pip install pyinstaller
pyinstaller --noconsole --onedir --name ScreenshotSplitter main.py
```

生成目录为 `dist/ScreenshotSplitter/`。

如需单文件 EXE：

```bash
pyinstaller --noconsole --onefile --name ScreenshotSplitter main.py
```

对于超长图片，优先推荐 `--onedir` 版本。

## 项目原则

预览层负责显示和交互，原始图片数据负责最终导出。所有缩放、平移、选中框和删除区域遮罩均只影响预览状态，不修改原始图片。
