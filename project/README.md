# Screenshot Splitter

Windows 10/11 长截图水平分割工具。项目采用 Python + PySide6，目标是提供直接的“分割线 + 区域筛选 + 批量导出”工作流。

## 功能

- 打开 PNG 长截图并在预览窗口中编辑。
- 添加、拖动、删除水平分割线。
- 点击区域进行选择，并切换区域的保留/删除状态。
- 使用方向键微调选中的分割线。
- 使用 `Alt + 滚轮` 缩放预览，并以鼠标位置为缩放中心。
- 使用鼠标左键或中键拖动预览画布；普通滚轮和 `Shift + 滚轮`用于滚动。
- 使用 `F` 让图片自动适应当前预览窗口。
- 使用 `1` 以原始尺寸（1:1）显示图片。
- 删除区域使用可调透明度的半透明预览遮罩。
- 将保留区域按原始像素裁剪并导出为连续编号的 PNG 文件。
- 预览缩放、平移和遮罩不会修改原始图片，也不会影响导出尺寸或画质。

详细的模块接口、项目结构和开发进度见 `开发文档/`。

## 使用方法

### 安装依赖

建议使用 Python 3.11+。

```bash
pip install -r requirements.txt
```

### 运行

```bash
python main.py
```

### 基本操作

1. 点击“打开”，选择 PNG 长截图。
2. 图片打开后会自动适应预览窗口并居中。
3. 默认按 `S` 在鼠标所在位置添加水平分割线。
4. 点击分割线并拖动，可调整分割线位置。
5. 点击图片区域可选择区域；按 `Space` 切换当前区域的保留/删除状态。
6. 按 `F` 可随时重新适应窗口，按 `1` 以原始尺寸显示。
7. 使用 `Alt + 鼠标滚轮`进行放大或缩小；滚轮向前放大，向后缩小。
8. 使用鼠标左键或中键拖动画布查看图片的其他位置。
9. 删除区域会显示半透明遮罩，可通过“遮罩设置”调整透明度。
10. 点击“导出全部”，选择输出目录，导出所有保留区域。

### 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `S` | 在鼠标位置添加分割线 |
| `Space` | 切换当前区域保留/删除 |
| `Delete` | 删除选中的分割线 |
| `↑ / ↓` | 分割线移动 1px |
| `Shift + ↑ / ↓` | 分割线移动 10px |
| `Alt + 滚轮` | 以鼠标位置为中心缩放 |
| `F` | 适应窗口并居中 |
| `1` | 原始尺寸（1:1） |
| 左键 / 中键拖动 | 平移画布 |
| 普通滚轮 | 垂直滚动 |
| `Shift + 滚轮` | 水平滚动 |

“设置快捷键”页面可以修改配置中的快捷键字符串。当前部分复杂组合键尚未完全接入运行时快捷键解析。

## 调试日志

默认不启用日志。开发或排查问题时，使用一个参数即可启用推荐的默认日志配置：

```bash
python main.py --log
```

默认配置记录：

- 应用启动、退出和未捕获异常。
- 启动时的运行上下文，包括进程 ID、Python 版本、实际命令行参数和启用的日志分类。
- 文档、分割线、区域、缩放和预览状态变化。
- 启动时的快捷键配置快照。

默认配置不会记录连续鼠标移动，也不会安装全局 GUI 事件过滤器，因此正常调试不会产生大量高频记录。

需要进一步定位 GUI 事件链时，可追加以下选项：

| 参数 | 额外记录内容 |
| --- | --- |
| `--log-events` | QApplication 实际收到的键盘、鼠标按键和滚轮事件 |
| `--log-interaction` | 画布按下、释放、平移开始/结束、每次平移及滚动条变化等内部交互状态 |
| `--log-mouse-move` | 鼠标移动轨迹；连续且状态不变的移动会合并为一条 `mouse_move_segment` |

例如，排查“鼠标按下了但画布没有拖动”时，可使用：

```bash
python main.py --log --log-events --log-interaction
```

只有需要分析具体鼠标移动轨迹时，再增加 `--log-mouse-move`。各细化选项均为追加项，不需要同时指定多个才能启用日志。

日志以 JSONL 格式保存到程序运行目录的 `logs/` 下，每次启动创建一个新的 `debug_*.jsonl` 文件。日志写入失败不会影响主程序运行。

更详细的日志字段、分类和分析方法见 `开发文档/调试日志.md`。

## 配置

程序会在运行目录保存 `settings.json`，用于保存快捷键和预览遮罩透明度配置。配置文件无法读取时会恢复为默认配置，不阻止程序启动。

## 依赖

项目运行依赖位于 `requirements.txt`：

- Python 3.11+
- PySide6 6.7 以上、7 以下
- Pillow 10.0 以上、13 以下

## Windows 打包

使用 PyInstaller 打包：

```bash
pip install pyinstaller
pyinstaller --noconsole --onedir --name ScreenshotSplitter main.py
```

生成目录为 `dist/ScreenshotSplitter/`。

如需单文件 EXE：

```bash
pyinstaller --noconsole --onefile --name ScreenshotSplitter main.py
```

对于超长图片，优先推荐 `--onedir` 版本。

## 项目原则

预览层负责显示和交互，原始图片数据负责最终导出。所有缩放、平移、选中框和删除区域遮罩均只影响预览状态，不修改原始图片。
